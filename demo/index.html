Architecture
Thread Model (single process)
• Main thread — accept() loop :8080
• Worker pool (16) — handle_client() × N
• Health check — HTTP HEAD / 5 s
• Stats thread — JSON on :8081
• SIGHUP thread — sigwait() reload
Key Design Decisions
• TOCTOU-free — single mutex for select + increment
• atomic<Algorithm> — lock-free reads in workers
• SO_REUSEADDR — instant restart after crash
• Retry on connect fail — next healthy backend
• sigwait() — safe async signal handling
